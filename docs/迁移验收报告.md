## 3. 发现并修复的问题

迁移前的工作区里，`chatCompletionsUrl` 改成了优先读取 `ASSISTANT_BASE_URL`。视觉识别 `recognition.js` 也调用这个函数，结果视觉请求（`gpt-5.6-terra`）会发到 TokenHub，却带着 `OPENAI_API_KEY` 的 Key。修复方法是给视觉单独加一个 URL 函数，并补了回归测试。
