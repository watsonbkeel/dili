# 本地历史导览小程序改版关联图片生成 Prompts

## 统一风格总提示词

后续每张图都建议先加上这一段，保证图片风格统一：

```text
生成一张微信小程序中文界面设计图，画面为 iPhone 手机界面 mockup，竖屏比例 9:16，界面主题是“本地历史导览小程序”。整体视觉延续现有小程序风格：米白背景 #f6f4ef、深绿色主色 #15937f、深文字 #18212f、浅绿色功能标签、白色卡片、细灰色边框，界面清爽、真实、可开发落地。

设计应像真实微信小程序页面，而不是宣传海报。不要使用夸张渐变、不要做营销落地页、不要使用英文大段文案。文字为简体中文，按钮和页面标题清晰可读。卡片圆角适中，不要过度圆润。页面应有微信小程序顶部导航感和底部 TabBar 感。

底部导航统一为：首页、拍照、路线、我的。当前页面对应的 Tab 使用绿色高亮。整体强调文化旅行、历史导览、AI 识别、路线计划和无障碍体验。
```
