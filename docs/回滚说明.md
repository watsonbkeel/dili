# dili 回滚说明

按影响从小到大排列，优先用上面的方式。

## 1. 只回滚语音识别（不动代码、不动 DNS）

在新服务器 `/etc/dili/dili.env` 中改为：

```bash
SPEECH_TO_TEXT_PROVIDER=openai-compatible
SPEECH_TO_TEXT_URL=http://<可达的旧 Qwen ASR 地址>/v1/audio/transcriptions
```

然后 `sudo systemctl restart dili`。对外接口 `/api/transcriptions` 与返回 `{text}` 不变。
注意：旧 ASR 在旧服务器 127.0.0.1:3102，只本机可达；需要走内网或 SSH 隧道，不要把 3102 暴露到公网。

## 2. 回滚代码版本（新服务器上）

```bash
sudo bash /opt/dili/current/deploy/tencent/rollback.sh          # 回到上一个版本
sudo bash /opt/dili/current/deploy/tencent/rollback.sh <sha>    # 回到指定版本
ls /opt/dili/releases                                           # 查看可用版本
```

只切换 `/opt/dili/current` 软链并重启服务，不改 `/var/lib/dili` 数据。

## 3. 回滚数据

```bash
ls /var/lib/dili/backups/            # pre-restore-* 为每次恢复前自动保留的数据
sudo bash restore-data.sh /var/lib/dili/backups/dili-data-XXXX.tar.gz        # dry run
sudo bash restore-data.sh /var/lib/dili/backups/dili-data-XXXX.tar.gz --yes
```

## 4. 回滚流量到旧服务器（DNS 已切换后）

1. Cloudflare 把 `dili.bkeel.com` 的 A 记录改回旧 IP `43.161.244.217`。
2. 若切换后新服务器已产生新数据（问答记录、点赞），先在新服务器执行 `backup-data.sh`，再决定是否合并回旧服务器；不要直接覆盖旧 `store.json`。
3. 旧服务器在验收完成前保持运行、不删数据，所以这一步随时可用。

## 5. 不能回滚的事项

- 腾讯云 ASR 已产生的调用费用。
- 已删除的数据：迁移全程不删除旧服务器数据，恢复前自动保存 pre-restore 备份。
