## 本次核心目标

### 一、首次进入模式选择页

参考图片：

```text
/home/chennuo/project/docs/image1/选择模式.png
```

要求：

- 首次进入小程序时，不直接进入首页，而是进入模式选择页。
- 页面标题为“请选择适合你的使用方式”。
- 页面提供三类用户模式：
  1. 普通用户
  2. 视力障碍 / 低视力用户
  3. 行动不便用户
- “视力障碍 / 低视力用户”卡片必须是视觉重点：
  - 黑底白字
  - 高对比度
  - 大字号
  - 高度明显大于其他卡片
  - 约占首屏一半
  - 内部要有示例卡片
  - 示例卡片展示“故宫博物院”“播放讲解”“导航到这里”
- 普通用户和行动不便用户卡片保持图片中的白底绿色风格。
- 选择后保存用户模式：
  - `normal`
  - `lowVision`
  - `mobility`
- 用户模式后续影响首页、详情页、路线页。
- 后续可在“我的/设置”中重新选择模式，但如果当前实现成本高，先预留入口即可。

### 二、低视力用户首页

参考图片：

```text
/home/chennuo/project/docs/image1/弱视界面.png
```

要求：

- 低视力模式首页不是普通首页的简单放大版，而是独立适配布局。
- 页面标题为“大字语音导览”。
- 顶部显示状态：

```text
已开启：大字模式 · 高对比度 · 语音优先
```

- 页面整体为黑白高对比：
  - 白底
  - 黑字
  - 黑色粗边框
  - 超大按钮
  - 超大字号
- 首页优先显示三个大按钮：
  1. 听附近历史
  2. 找最近景点
  3. 问 AI 助手
- 附近景点推荐卡片只保留核心信息：
  - 景点名称
  - 距离
  - 一句话介绍
  - 听介绍
  - 导航到这里
- 不要展示复杂地图。
- 不要展示密集小标签。
- 不要依赖小图标。
- 所有主要点击区域必须很大。

### 三、低视力用户景点详情页

参考图片：

```text
/home/chennuo/project/docs/image1/弱视景点详情-1.png
```

要求：

- 使用黑底白字高对比风格。
- 页面顶部显示：

```text
大字模式 · 高对比度 · 语音优先
```

- 景点名称超大字号。
- 支持返回、收藏、主页/导航等顶部操作。
- 景点图片可以保留，但不能影响文字可读性。
- 地址、距离要清晰展示。
- 语音控制区必须突出：
  - 播放讲解
  - 暂停
  - 继续
  - 停止
  - 倍速（如可做，加入 `0.75x / 1x / 1.25x`）
- 要点摘要必须靠前展示：
  - 这个地方是什么
  - 和哪段历史有关
  - 到现场应该看什么
- 内容必须短句、短段落，不要大段文字。
- AI 助手入口保留，但不能遮挡核心内容。

## 交互规则

- 首次选择模式后保存到本地 storage。
- 再次进入小程序时，根据已保存模式进入对应首页。
- 用户可以后续切换模式。
- 普通用户进入普通首页。
- 低视力用户进入低视力首页。
- 行动不便用户进入轻松出行首页。
- 景点详情页根据当前模式切换不同布局：
  - `normal`：现有普通详情
  - `lowVision`：黑白高对比详情
  - `mobility`：行动不便详情
- 不能破坏现有功能：
  - 景点图片
  - 景点详情
  - 语音讲解
  - AI 助手
  - 路线页
  - 收藏
  - 导航到这里
  - 底部导航
  - 后端 API
- 能复用已有数据就复用。
- 无障碍信息如果当前没有真实数据，先使用清晰标注的演示数据，不要伪装成权威结论。
- 涉及故宫无障碍路线的内容，要写“建议出发前以景区官方信息为准”。
