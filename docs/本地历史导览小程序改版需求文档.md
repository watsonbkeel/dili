# 本地历史导览小程序改版需求文档

## 1. 项目目标

根据提供的设计稿，完成本地历史导览小程序的信息架构与主要页面改版，实现“发现历史、拍照识别、规划路线、个人中心”四个核心场景，并支持普通模式、无障碍出行模式、语音大字模式。

整体视觉以白底、历史文化感、绿色强调色为主；语音大字模式需独立采用黑白高对比度设计。

## 10. 语音大字模式首页

参考《语音大字模式首页.png》。

页面目标：

为视力较弱或偏好大字语音导览的用户提供更高可读性的首页。

调整要求：

1. 页面整体改为黑白高对比度：
   - 背景：纯白
   - 主文字：纯黑或接近纯黑
   - 边框：黑色或深灰
   - 不使用浅绿色底、浅绿色标签、低对比度灰字
2. 字体统一：
   - 页面所有中文使用同一字体风格
   - 不出现不同粗细/风格混杂导致的不统一
3. “城市：北京”字体需要变大：
   - 城市区域需比当前设计更醒目
   - 建议字号不小于页面普通正文的 1.4 倍
   - “城市：北京”整体保持一行展示
4. 保持白底黑字：
   - 不要黑底红字
   - 不要彩色警示块
5. 页面内容：
   - 标题：语音大字导览
   - 状态条：大字 · 高对比 · 语音优先 · 少步行
   - 城市：北京
   - 全部景点列表：故宫博物院、天坛公园、什刹海
   - 附近景点：景山公园，800 米，少台阶路线
6. 图标可保留，但需要高对比度：
   - 优先使用黑色图标
   - 当前选中 Tab 可使用黑底白字或黑色加粗，不使用低对比浅色
